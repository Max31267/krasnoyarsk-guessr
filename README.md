# Где это? — Красноярск

Небольшая браузерная игра в духе GeoGuessr: пять раундов с уличными панорамами Красноярска. Осмотрись в панораме, найди район на карте и поставь метку. За точное попадание начисляется больше очков.

## Запуск

Открой `index.html` в браузере. Для карт и панорам нужно подключение к интернету.

## Публикация

Статический сайт рассчитан на GitHub Pages. Панорамы загружаются через Google Maps, карта — OpenStreetMap / Leaflet.
